A tablebase for a cooperative game

A helpmate is a chess problem in which Black moves first and both sides cooperate to checkmate Black as quickly as possible. h#3 means mate after three moves by each side. A helpmate is only a sound problem when it has exactly one solution; a second one is a dual.

Because both sides want the same thing, the value of a position is a plain shortest path, and a whole material class can be solved at once. For every legal position in a class these tables store the distance to mate and the number of distinct optimal solutions. The second number is the one that tells a composer whether a position is a problem.

What is here: the deepest sound problem in every material class, 1071 puzzles with a unique solution you can solve on the board, and the corpus, table by table.

These positions were enumerated, not composed. No authorship is claimed over them and a generated database anticipates nobody — a composer who independently arrives at one of these positions is unaffected. Authorship and what this corpus is for →
